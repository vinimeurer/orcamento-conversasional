# Perfil do usuário

Nenhuma informação ainda. O Nanobot preenche este arquivo automaticamente
conforme aprende preferências do usuário ao longo das conversas (ex:
categorias que ele usa com mais frequência, forma de pagamento padrão).

Você pode editar este arquivo manualmente a qualquer momento para adicionar
contexto fixo, por exemplo:

```
- O usuário costuma registrar despesas no fim do dia, geralmente à noite.
- Forma de pagamento mais usada: cartão de crédito.
```
